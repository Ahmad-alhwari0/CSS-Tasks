# Product Card

A responsive product card built with HTML and CSS, based on a provided design reference.

## Features

- Sticky top navigation bar that stays visible while scrolling
- Product card with rounded corners and a discount badge on the corner
- Hover effect on the product image (zoom-in)
- Discounted price shown alongside the original price (struck through)
- "Add to Cart" and "Add to Wishlist" buttons
- Fixed low-stock notification
- Fully responsive layout for small screens

## Tech Stack

- HTML5
- CSS3 (Flexbox)
